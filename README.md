# Français

A personal, system-first French grammar study page, built to accompany conversation practice.

- `CURRICULUM.md`: the course plan (phases, units, page specification)
- `DESIGN.md`: the visual system (Cahier notebook, ink colour grammar, Ardoise dark mode)
- `design/mockup.html`: reference mockup of one unit
- `index.html`: the study page (open directly in a browser; no build step)

Private study repo.
