# Français: Grammar Curriculum

A personal, system-first French grammar course that runs alongside AI conversation practice. This document is the plan; the interactive study page (`index.html`) is built from it.

Started: November 2026

---

## 1. Learner profile

| | |
|---|---|
| **Starting level** | A0 to A1 on the CEFR (Common European Framework of Reference for Languages) |
| **Oral practice** | AI-based conversations, no fixed grammar syllabus. This page is therefore the grammar backbone. |
| **Goals** | Daily life and travel; professional exchanges with francophone collaborators; DELF (Diplôme d'études en langue française) certification; reading ideas (philosophy, science, literature) in the original |
| **Priority order** | Speaking support first; stay aligned with DELF grammar inventories; let reading grow steadily alongside |
| **Time budget** | Under 1 hour per week on this page |
| **Languages known** | Mandarin, English (both fluent); conversational German without formal grammar training |
| **Explanation style** | System-first: structure, paradigms and the logic of the system before drills |
| **Audio** | Every French sentence can be narrated; listening is part of each unit. AI conversation prompts stay outside the page. |

---

## 2. Design principles

1. **Grammar as a system, not a list.** Each unit opens with the structure: what features the system tracks (gender, number, person, tense, aspect, mood), how forms are generated (stem + ending, slot templates), and where the irregularities sit. Rules of thumb come after the model, not instead of it.
2. **Spoken and written French are two paradigms.** French spelling preserves distinctions that speech has lost. *Je parle, tu parles, il parle, ils parlent* are four persons and three spellings but a single spoken form /paʁl/. Every unit states both paradigms explicitly, because the spoken one is what the conversation practice uses and the written one is what DELF and reading use.
3. **Speaking-first ordering.** Topics are sequenced by how soon they are needed in conversation (present tense, questions, near future, past) and checked against the DELF A1, A2 and B1 grammar inventories so nothing the exam expects is skipped.
4. **Cross-language anchors, used sparingly.** A comparison to English, Mandarin or German appears only when it genuinely clarifies the mechanism (for example, German *Perfekt* with *haben/sein* for the *passé composé* with *avoir/être*; Mandarin 了 as a rough handle on perfective aspect). Anchors are flagged as approximate where they are.
5. **Small doses, spaced and interleaved.** With under an hour per week, retention comes from the review queue rather than from long sessions. Every completed item feeds a spaced repetition system (SRS), and consolidation weeks mix earlier units.
6. **Metalanguage migrates into French.** Explanations start in English with French grammatical terms in parentheses (*le sujet*, *l'accord*), become bilingual in the A2 phase, and lean French in the B1 phase. This quietly trains the reading of French prose about language.

---

## 3. Weekly rhythm (about 45 to 50 minutes)

One unit per week by default. A unit can be repeated or split without breaking the plan; consolidation weeks are the buffer.

| Session | Length | Content |
|---|---|---|
| 1. *Le système* | ~15 min | Read the structural explanation, study the paradigm tables, listen to the examples (normal and slow speed) |
| 2. *Exercices* | ~10 min | Form drills and cloze sentences on the new structure |
| 3. *Écoute et production* | ~10 min | Dictation, transformation drills, short translation into French |
| 4. *Révision* | ~10 min | SRS review queue from all earlier units, then the unit's short reading |

The AI conversations can then use the week's structures naturally; the page does not script them.

---

## 4. Anatomy of a unit

Each unit on the page has the same sections, in this order:

1. **Objectif**: a can-do statement in CEFR style (e.g. *I can say what I did yesterday*).
2. **Le système**: the structural model, with paradigm tables and generation rules.
3. **À l'oral / À l'écrit**: where the spoken and written paradigms diverge (silent endings, liaison, elision).
4. **Ancrages**: one or two cross-language anchors, only if useful.
5. **Exemples**: 8 to 12 sentences, each clickable for audio, with gloss on demand.
6. **Pièges**: the predictable errors and false friends for this structure.
7. **Exercices**: a mixed drill set (types in §8.3).
8. **Lecture**: a short graded text using the unit's structures; length and authenticity grow by phase.
9. **Vocabulaire**: 12 to 20 high-frequency words for the unit's theme, which the drills and reading use.

## 5. Roadmap overview

| Phase | Level | Units | Weeks (approx.) | Focus |
|---|---|---|---|---|
| 0. Fondations | pre-A1 | F1 to F2 | 2 | Sound/spelling system; gender and number as features |
| 1. Survie | A1 | 1 to 18 | 18 | Present tense, questions, determiners, near future, *passé composé*, imperative |
| 2. Raconter | A2 | 19 to 34 | 16 | Object pronouns, *imparfait* vs *passé composé*, future, relatives, conditional |
| 3. Nuancer | B1 | 35 to 45 | 11 | Subjunctive, pluperfect, reported speech, hypotheticals, argument connectors |
| 4. Lire | toward B2 | outline | open | Literary and academic grammar for reading (*passé simple*, nominalisation, etc.) |

At one unit per week this covers the B1 grammar inventory in roughly 47 weeks. Grammar coverage is not the same as proficiency: the DELF also tests listening, reading, writing and speaking under exam conditions, so an exam-format practice track is added a few weeks before any exam you decide to sit (§7.4).

## 6. Units

Columns: **System idea** is the structural point the unit is built around. **Anchor** is an optional comparison (EN English, 中 Mandarin, DE German).

### Phase 0: Fondations (pre-A1)

| # | Topic | System idea | Anchor |
|---|---|---|---|
| F1 | Sounds and spelling | Spelling-to-sound map: silent final consonants, nasal vowels, what the accents (é è ê ç) actually encode; liaison and elision as the rules that rejoin words in speech | EN: many shared letters, very different mapping |
| F2 | Gender and number | Every noun carries gender (m/f) and number; the article is the main audible carrier of both, because plural *-s* is usually silent. *le, la, l', les; un, une, des* | DE: gender exists but assignments do not transfer (*der Mond / la lune*); 中: no grammatical gender, so this is a new feature to track |

### Phase 1: Survie (A1)

| # | Topic | System idea | Anchor |
|---|---|---|---|
| 1 | Subject pronouns and *être* | Person/number grid; *tu* vs *vous* (familiarity and plurality); *on* as the everyday spoken "we"; *c'est* vs *il est* (intro) | DE: *du / Sie* |
| 2 | *Avoir*, *il y a*, negation | *ne ... pas* wraps the conjugated verb; *un/une/des* become *de* after negation; *ne* usually dropped in speech | 中: 有 covers both *avoir* and *il y a* |
| 3 | Present of *-er* verbs | Stem + ending generation; written paradigm has 5 distinct forms, spoken has 3 | EN: *-s* agreement is a remnant of the same kind of system |
| 4 | Asking questions | Three registers: intonation (spoken), *est-ce que* (neutral), inversion (formal, recognition only); question words | 中: like 吗 vs question-word-in-place; French also allows *Tu vas où ?* |
| 5 | Adjectives | Agreement as feature copying from noun to adjective; default position after noun, short common ones before (beauty, age, goodness, size); *beau/bel/belle* | |
| 6 | **Consolidation 1** | Mixed review of F1 to 5, checkpoint quiz | |
| 7 | Possessives and demonstratives | Possessive agrees with the **possessed** noun, not the owner (*sa mère* = his or her mother); *ce/cet/cette/ces* | DE: *sein/ihr* distinguishes owner; French does not |
| 8 | *Aller, faire, venir*; near future | High-frequency irregulars; *aller* + infinitive as the spoken default future | EN: *going to* |
| 9 | Prepositions and contractions | *à/de + le/les → au, aux, du, des*; prepositions with cities and countries; place and time | DE: *zu dem → zum*, same idea |
| 10 | Partitive articles | Count vs mass marking: *du, de la, des*; quantities (*beaucoup de*, *un peu de*) | 中: no articles; EN: *some*, often unmarked |
| 11 | Modal verbs | *pouvoir, vouloir, devoir* + infinitive; *il faut*; polite *je voudrais* | DE: *können, wollen, müssen* |
| 12 | **Consolidation 2** | Mixed review of 7 to 11 | |
| 13 | Reflexive verbs | Pronoun co-indexed with the subject (*je me lève*); daily routine | DE: *sich*, near-identical logic |
| 14 | *Passé composé* with *avoir* | Auxiliary + past participle; participle formation by verb group | DE: *Perfekt* with *haben* |
| 15 | *Passé composé* with *être* | Motion/change-of-state verbs and all reflexives take *être*; participle agrees with subject | DE: *Perfekt* with *sein*, largely the same verb class |
| 16 | Time in the past | *venir de* + inf. (just did); *il y a* (ago), *depuis* (since/for, with present tense), *pendant* | EN: *I have been living here for* = *j'habite ici depuis* (present, not past) |
| 17 | Imperative | Three forms (*tu, nous, vous*); *-er* verbs drop the *-s* in the *tu* form; pronouns after the verb | |
| 18 | **Consolidation 3 + A1 checkpoint** | Mixed review; checkpoint mirroring the DELF A1 grammar inventory | |

### Phase 2: Raconter (A2)

| # | Topic | System idea | Anchor |
|---|---|---|---|
| 19 | Direct object pronouns | *le, la, l', les* occupy a fixed slot **before** the conjugated verb | DE: accusative *ihn, sie, es* |
| 20 | Indirect object pronouns | *lui, leur*; verbs that take *à* (*parler à, téléphoner à*) | DE: dative *ihm, ihr*; the direct/indirect split maps onto accusative/dative |
| 21 | *y* and *en* | *y* replaces *à* + thing/place; *en* replaces *de* + thing and quantities (*J'en ai deux*) | No equivalent in EN/中/DE; a genuinely new category |
| 22 | Pronoun order | The clitic template: *me/te/se/nous/vous* > *le/la/les* > *lui/leur* > *y* > *en* > verb. Learned as a slot grammar | |
| 23 | **Consolidation 4** | Mixed review of 19 to 22 | |
| 24 | *Imparfait*: formation | Stem from the *nous* present form + one ending set; *être* is the only irregular stem | |
| 25 | *Passé composé* vs *imparfait* | Aspect: perfective (bounded event) vs imperfective (background, state, habit). Narrative foreground vs background | 中: 了 roughly marks bounded events; 在/着/常常 cover ongoing and habitual (approximate) |
| 26 | Future tense | Infinitive + endings from *avoir*; irregular stems (*ser-, aur-, ir-, fer-*); *futur proche* vs *futur simple* in speech | |
| 27 | Comparatives and superlatives | *plus/moins/aussi ... que*; *meilleur* vs *mieux* (adjective vs adverb) | EN: *better* collapses both |
| 28 | **Consolidation 5** | Mixed review of 24 to 27 | |
| 29 | Relative pronouns I | *qui* (subject), *que* (object), *où* (place and time) | 中: 的 before the noun; French relatives follow the noun |
| 30 | Relative pronouns II | *dont*; *ce qui / ce que* (what) | |
| 31 | Negation expanded | *ne ... jamais / rien / personne / plus / que*; *rien* and *personne* as subjects | |
| 32 | Conditional present | Future stem + *imparfait* endings; politeness, wishes, *si* + *imparfait* → conditional | DE: *Konjunktiv II* / *würde* |
| 33 | Stressed pronouns and spoken syntax | *moi, toi, lui, elle*; *c'est moi qui*; dislocation (*Moi, je pense que...*; *Ce film, je l'ai vu*) | 中: topic-comment structure (这部电影，我看过) |
| 34 | **Consolidation 6 + A2 checkpoint** | Mixed review; DELF A2 grammar inventory | |

### Phase 3: Nuancer (B1)

| # | Topic | System idea | Anchor |
|---|---|---|---|
| 35 | Subjunctive: formation | Stem from *ils* present + endings; the irregular core (*être, avoir, aller, faire, pouvoir, savoir, vouloir*) | |
| 36 | Subjunctive: triggers | Mood as a semantic system: will, necessity, emotion, doubt (*il faut que, je veux que, bien que*) vs assertion (indicative) | |
| 37 | *Plus-que-parfait* and narrative time | Anteriority in the past; sequence of past tenses in a story | EN: *had done* |
| 38 | Reported speech | Tense shift (*concordance des temps*); deictic shifts (*demain → le lendemain*) | EN: similar backshift rules |
| 39 | **Consolidation 7** | Mixed review of 35 to 38 | |
| 40 | *Gérondif* and present participle | *en* + *-ant* for simultaneity and manner | 中: 一边...一边... |
| 41 | Passive voice and alternatives | *être* + participle; *on* and *se faire* as the more idiomatic spoken alternatives | DE: *werden*-Passiv |
| 42 | Full hypothesis system | Three *si* patterns: real, unreal present, unreal past (conditional past) | DE: *hätte ... gemacht* |
| 43 | Argument connectors | Cause, consequence, concession, opposition (*donc, pourtant, bien que, alors que, en revanche*): the scaffolding of DELF B1 writing and of argumentative reading | |
| 44 | Compound relatives | *lequel, auquel, duquel*; *ce dont*; preposition + relative | |
| 45 | **Consolidation 8 + B1 checkpoint** | Mixed review; DELF B1 grammar inventory | |

### Phase 4: Lire (toward B2, outline)

Grammar mainly needed to **recognise** in written French, ordered by how often it blocks reading of essays, philosophy and literature:

- *Passé simple* (recognition first: the narrative tense of written French)
- Subjunctive past; *futur antérieur*; conditional past in argument
- Nominalisation and the noun-heavy academic register
- Literary and formal inversion; *ne* explétif (*avant qu'il ne parte*)
- Long relative and participial constructions
- Graded progression of authentic texts (essays, popular science, then primary philosophical texts)

This phase is planned in detail once Phase 3 is under way, based on what you are reading by then.

## 7. Threads running through all units

### 7.1 Vocabulary

Each unit carries 12 to 20 words chosen from high-frequency French and tied to conversation themes in roughly this order: introductions, family and people, food and cafés, the city and transport, daily routine, work and research, travel, health, opinions and debate. From Phase 2 on, a small academic strand is added (Latinate vocabulary that maps closely onto English: *-tion*, *-ité*, *-ment*), which speeds up reading. False friends get flagged (*actuellement* = currently; *librairie* = bookshop; *éventuellement* = possibly).

### 7.2 Listening and audio

Every French string on the page can be spoken aloud. Each unit has a listen-through of its examples, dictation items, and a shadowing mode (sentence plays, pause to repeat, sentence replays). This is the bridge to the oral practice without scripting it.

### 7.3 Reading

| Phase | Reading diet |
|---|---|
| 0 to 1 | Signs, menus, short messages, simple self-descriptions (40 to 80 words) |
| 2 | Short narratives, emails, everyday news-style paragraphs (100 to 200 words) |
| 3 | Opinion pieces, adapted popular science and essay excerpts (200 to 400 words) |
| 4 | Authentic texts with glossing support |

### 7.4 Exam readiness

Each phase ends with a checkpoint keyed to the DELF grammar inventory for that level. If you decide to sit an exam, a short exam-format track (timed tasks across the four skills) is added in the weeks before. The current format and session dates should be checked with France Éducation international and your local exam centre at that point, since both change.

## 8. Study page specification

### 8.1 Core features

- **Unit browser**: phases and units in a sidebar, with completion state.
- **Unit view**: the sections of §4, rendered from unit data files.
- **Audio (TTS, text-to-speech)**: uses the browser's built-in speech synthesis with a French (fr-FR) voice; click any French sentence to hear it; speed presets (slow 0.7, medium 0.85, normal 1.0); listen-through and shadowing modes. Voice quality depends on the system voices installed: on macOS the enhanced French voices can be downloaded in the Spoken Content settings.
- **Drill engine** with immediate feedback and an explanation for each item.
- **Review queue (SRS)**: a five-box Leitner scheme. Correct moves an item up a box (longer interval), wrong sends it back to box 1. Intervals: 1, 3, 7, 16, 35 days.
- **Accent bar**: one-click é è ê ë à â ç î ï ô û ù œ for typing answers.
- **Fiches**: tap any French word for its meaning and grammatical analysis, with the sentence translation one step further; looked-up words can be added to the review queue (details in `DESIGN.md` §7).
- **Progress**: saved in the browser, with export/import to a `progress.json` file so it can be committed to the repo and moved between machines.
- **Light and dark themes**.

### 8.2 Answer checking

Answers are normalised (case, spacing, curly vs straight apostrophes) before comparison. Each item can list several accepted answers. An answer that is right except for accents is marked *presque* (almost) and shown with the accents highlighted, rather than marked plainly wrong.

### 8.3 Drill types

| Type | What it does | Example |
|---|---|---|
| `form` | Generate a form from features | *parler*, nous, présent → *parlons* |
| `cloze` | Fill a gap in a sentence | *Je ___ (aller) au cinéma.* |
| `transform` | Rewrite a sentence under a rule | negate it; replace the object with a pronoun; put it in the past |
| `choose` | Pick between contrasting forms | *passé composé* or *imparfait* in context |
| `translate` | English to French, short sentences | several accepted answers |
| `dictee` | Hear a sentence, type it | trains the spoken-to-written mapping |
| `spot` | Find and fix the error | *Hier, j'ai allé au marché.* → *je suis allé* |
| `sort` | Classify items | sort nouns by gender; verbs by auxiliary |

### 8.4 Technical choices

- Plain HTML, CSS and JavaScript; no build step, no dependencies, so the page works by opening `index.html` directly and also on GitHub Pages.
- Unit content lives in one JavaScript file per unit (each calling `registerUnit({...})`) rather than JSON (JavaScript Object Notation) files, because browsers block loading local JSON files when a page is opened straight from disk.
- GitHub Pages from a **private** repository requires a paid GitHub plan; on the free plan the page is simply opened locally from the cloned repo.
